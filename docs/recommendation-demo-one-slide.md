# 迷わせないレコメンド
## 意味化した情報基盤をAIが参照し、利用フィードバックで育つ

---

| **入力** | **意味化情報基盤** ★ | **出力** |
|:--|:--|:--|
| 顧客の回答・価値観 | **Need** — 実現したいこと | おすすめサービス |
| ↓ 構造化・意味化 | **Load** — 避けたい懸念 | 適合度・推薦理由 |
| | **Service** — 提案可能なサービス | **参照した情報**（Need / Load / Service） |
| | それらの**関係性** | 利用FBによるスコア調整 |

---

### 本デモの3点

1. **説明できる** — なぜこの提案かが見える（ブラックボックスではない）
2. **AIは覚えない** — 構造化・意味化した情報基盤を**参照**する
3. **育つ** — 利用フィードバックで基盤と提案精度が改善する

---

**AIの賢さではなく、「AIが参照する意味化情報基盤」の価値を示すPoC**
